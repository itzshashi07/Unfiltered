# Claims that need expert review before any public release

**Status of the whole curriculum: not reviewed.** The content was drafted with AI assistance against the
sources in `assets/content/references.json`. No doctor, lawyer, psychologist or child-safeguarding
specialist has checked it. Every lesson carries `"review": "pending_expert_review"`, and the app says so on
every lesson, answer and myth card.

This file lists the specific claims the content authors themselves flagged as going beyond the agreed fact
sheet (`docs/CONTENT_SCHEMA.md`, section 3) or as ones they were not certain of. It is a starting list for
reviewers, not a complete audit: everything else still needs reading too.

Item IDs (for example `d07-l05`, `d16-f09`) are the IDs in the JSON packs; `l` = lesson, `f` = FAQ,
`m` = myth card, `q` = quiz, `s` = scenario.

## 3. Safeguarding and editorial judgement calls

- **Ages 13–15 see PEP/EC time limits** (awareness level) because the windows matter after assault. Narrow to 16+ if the school prefers.
- **Ages 16–17 see correct-use points for condoms** (`d07-l02`), framed as knowledge with POCSO context.
- **Slurs are named in order to reject them** for ages 13+ (`d11-l05`, `d11-f09`).
- **A vaping/peer-pressure scenario** is used for ages 13–15 (`d18-s3`); every path models refusing.
- **Search keywords include everyday slang** (for example in the masturbation and emergency-pill FAQs) so learners can find answers. Keywords are never displayed.
- **Reassurances to children** such as "you will not be in trouble for telling" are standard child-safety messaging, not guarantees.
- **"Sensitive" flags** decide where the app skips celebration: all of d14 and d16, d05-l04 to l06, d08-l02 to l05, d11-l04, d17-l04. d05-l01 to l03 (body-autonomy basics) celebrate.
- **Hindi register**: "तुम" for younger tracks, "आप" for adults; Hindi uses the generic masculine in places. A Hindi editor should review tone and gendered forms.
- **Reporting tools not named**: StopNCII and NCMEC "Take It Down" were left out because they are not in the reference registry and involve uploading hashes of images; a reviewer may want to add guidance.
- **Reference fit**: some general claims cite `unesco-itgse` as the nearest source. Check each citation actually supports its claim.

`pending_expert_review`) and the wording of `review.pending` in `lib/core/strings.dart`.
